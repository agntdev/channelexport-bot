# ChannelExport Bot

Telegram bot that fetches all channel messages and media, producing downloadable XLSX/CSV export files with resumable historical sync and near-real-time updates.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
